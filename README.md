# java-calculator

Консольный калькулятор: практическое задание к модулю 2 курса «Программирование на языке Java» (МИФИ, SkillFactory).

## Запуск

```bash
javac Calculator.java
java Calculator
```

## Что умеет

- Считывает число, операцию (`+`, `-`, `*`, `/`) и второе число, выводит результат.
- Результат становится первым числом следующей операции.
- `C` сбрасывает результат, `S` выключает калькулятор, регистр не важен.
- При делении на ноль и неподдерживаемой операции выводит сообщение, результат не меняется.
- Дробные числа можно вводить через точку или запятую.

## Пример

```text
Калькулятор. Операции: + - * /
Команды: C - сбросить результат, S - выключить.
Введите число: 2
Введите операцию: +
Введите второе число: 3
Результат: 5
Введите операцию: /
Введите второе число: 0
Ошибка: деление на ноль. Результат не изменился: 5
Введите операцию: c
Результат сброшен.
Введите число: s
Калькулятор выключен.
```
